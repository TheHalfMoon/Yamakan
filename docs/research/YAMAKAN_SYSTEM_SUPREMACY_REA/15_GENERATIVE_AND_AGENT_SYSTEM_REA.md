# R-02: generative and agent-native system research

Research date: 2026-11-02. This is a primary-documentation and bounded source-inspection assessment. No competitor account, paid session, model, upload or generation was used. Runtime reliability, latency, visual quality and undocumented persistence guarantees are **UNKNOWN** for every closed product. Documentation describes advertised interaction contracts; it does not prove transactional implementation. Research coverage is ready for independent review, not VERIFIED by publication of this file.

## Twenty-dimension disposition

This matrix applies to all products above; a row-specific observation overrides UNKNOWN only for the named behavior. It prevents a workflow screenshot from becoming an undocumented architecture claim.

| Dimension              | Evidence / final planning treatment                                                                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Journey                | Documented sequences above; Yamakan SS-004b proves the model-free full journey.                                                                                     |
| Workflow               | Clip modification, shot planning and assembly are distinct operations; preserve that distinction.                                                                   |
| Project structure      | Use existing canonical project/story/shot/take documents; closed backing schemas UNKNOWN.                                                                           |
| Assets                 | Keep immutable originals and project-owned references; no assumption that cloud history is backup.                                                                  |
| References             | Bind asset hash, declared role and consent; vendor resemblance claims untested.                                                                                     |
| Scenes                 | Existing story IDs define scope; no second scene database.                                                                                                          |
| Cinematic controls     | Intent metadata only until an authorized engine demonstrates a supported capability.                                                                                |
| Timeline               | Exact rational Yamakan time; closed precision/rounding behavior UNKNOWN.                                                                                            |
| Orchestration          | Typed Director manifests; graph interfaces do not prove execution durability.                                                                                       |
| Automation             | Registered commands only; no unrestricted scripts, tools or browser action authority.                                                                               |
| Agent behavior         | Read/propose/review/apply remains inspectable; scoped mutation authorization stays explicit.                                                                        |
| History                | Append-only receipts and per-writer undo; snapshots and generated versions are different contracts.                                                                 |
| Revisions              | Existing `TakeProposalSchema` binds project revision, story hash and mapping; SS-006 wraps it.                                                                      |
| Export                 | Current FFmpeg output plus qualified OTIO subset; disclose unsupported interchange features.                                                                        |
| APIs / SDK / CLI / MCP | Public API contracts observed only where linked; closed internal transport UNKNOWN. Yamakan transport parity is SS-007.                                             |
| Prices / resources     | Paid or credit boundaries identified; exact costs/account quotas UNKNOWN and deliberately not used as a design input. No purchase or provider execution authorized. |
| Limitations            | Model restrictions, beta labels, inaccessible docs and uninspected source closures recorded per row.                                                                |
| Reliability            | Competitor runtime UNKNOWN. Yamakan recovery/resource claims require current exact-artifact tests.                                                                  |
| User value             | Review a targeted change, preserve original work, continue manually and export an honest artifact.                                                                  |
| Possible advantage     | Selective revision with unchanged unrelated shots is a hypothesis measured by SS-016, not a competitive superiority claim.                                          |

## Result and gates

All 16 generative groups and 11 agent-native names in [02](02_RESEARCH_EXECUTION_PLAN.md) have an explicit bounded disposition. No closed product is an implementation donor. New engineering uses existing Yamakan commands and the qualified boundary/test concepts in [01](01_COMPETITOR_AND_SOURCE_REA.md). Runtime/source access limitations do not require subscriptions to resolve: unsupported providers remain deferred. Fresh independent review must still check that these observations support the task contracts and do not overstate competitor verification.
