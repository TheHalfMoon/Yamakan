# What Yamakan can outperform, cannot match, and the shortest path

**Date:** 2026-10-22  
**Honesty rule:** “Can outperform” means **tested or strongly evidenced product properties today**, not aspirational marketing.

## 1. Where Yamakan can genuinely outperform *today*

These are categories where closed cloud video apps are typically weak or absent, and Yamakan already has **TESTED** or strong engineering evidence on the Windows QA path:

| Area | Why Yamakan can win now | Evidence grade |
| --- | --- | --- |
| Offline project ownership | Full local editable project; reopen/recover without cloud lock-in | TESTED (short campaign) |
| Deterministic edit → export | Timeline ops + FFmpeg export with provenance-minded pipeline | TESTED |
| Agent surface without egress | Typed MCP/REST + deny/explain when providers off | TESTED (unit/dev) |
| Security posture as default | Engine off, providers off, import policy, containment goals | DOCUMENTED + partial TESTED |
| Arabic/RTL product intent | Automated RTL qualification; bilingual plan | TESTED automated; native H1 NOT RUN |
| Reproducible jobs | Durable jobs, attemptKey fencing, fake-engine quarantine patterns | TESTED (fake path) |
| Cost transparency at $0 inference | No silent credit burn while engines off | TESTED by absence |

**Do not claim** superiority on T2V/I2V beauty, character AI, or Cinema optical conditioning — engines are off.

## 4. Shortest credible path to close gaps

Ordered for maximum learning per unit risk/cost:

### Path P0 — no F required (start immediately after this REA)

1. Expand **Category A** long-form edit benchmarks (real media, multi-track, Arabic).  
2. Close remaining security residuals that do not need engines (H1–H5 as scheduled).  
3. Design control-compiler + character-pack **schemas** as fixtures only (no inference).  
4. Keep public messaging: offline production studio; no AI-video superiority claims.

### Path P1 — requires founder F + capable GPU host (not the UHD laptop)

1. Land `EngineAdapter` real implementation behind `ENGINE_ENABLED=false` (E0–E1).  
2. Authorize **one** small Apache-friendly checkpoint: **Wan2.2 TI2V-5B** preferred; **CogVideoX-2B** alternate.  
3. Smoke three seeded prompts; quarantine/cancel tests; ledger hashes.  
4. Run **Category B/C subset** locally; label results TESTED.  
5. Only then consider blind compare vs one paid baseline **if** spend is separately approved.

### Path P2 — optional providers (separate budget)

1. Provider adapters for HF/Runway/Kling/Luma as **opt-in**, default off.  
2. Use marketplace for quality ceiling; keep Yamakan as timeline authority.  
3. Never auto-bill; never claim local > hosted without matched blinds.

### Path P3 — do not prioritize early

- LTX-2 / 14B Wan / Hunyuan on scarce disks  
- Full Comfy custom-node ecosystem  
- “Beat Artificial Analysis Elo” as a release gate  
- Public release before G
