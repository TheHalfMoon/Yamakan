## Model integration

No model is enabled or qualified in Yamakan, and none is downloaded to this machine. Two real models have made videos on Kaggle, brought in as files, and Wan2.2-TI2V-5B has been started from Yamakan's own page on the person's private notebook. `ENGINE_ENABLED` is false. Commercial providers are off. No media goes to a cloud service. A prompt and seed go to a person's own private Kaggle notebook only when they choose; only a read-only health check reaches ComfyUI, on this machine. It refuses partner nodes and a ComfyUI not started offline; `--offline` is not an egress block. By the founder's decision a person starts it, with no Yamakan sandbox.

## What blocks real generation

This laptop has no discrete GPU (Intel UHD, 15.7 GiB RAM, about 18 GiB free), so models run on Kaggle's free GPUs. See `comfyui-engine.md`. Building the path continues here; a real text-to-video result needs a machine that can run a model.
