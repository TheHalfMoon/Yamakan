# 08 — Source donor master matrix

Status: research and proposed adoption decisions only. Date: 2026-10-23. This review authorizes no imports, engine activation, model download, inference, packaging, or release. Existing qualified imports and release blockers remain in force.

## Decision

Preserve one canonical creative document graph and one owned media service. Extend the existing FFmpeg compiler and checked OpenCut algorithms; introduce OTIO as a lossy, reported interchange boundary. Resolve project cohesion and backup/CAS gaps before adding inference. Compare isolated Diffusers and ComfyUI workers against the same operation contract before choosing a local generation lane. Neither donor owns project persistence, timeline truth, durable job truth, approval truth, or publication.

The strongest reuse is smaller than an application: deterministic edit algorithms, immutable identity references, stage prerequisites, media processes, and operation workers. Kdenlive and Shotcut source shows why replacing the current service with their application internals would require a deliberate architecture migration, not a quick transplant. MLT deserves a measured preview challenger; it does not justify a parallel export authority today.

## Challenge to Diffusers-first and the worker boundary

Diffusers has the clearest small Python API and favorable library license among the generation candidates inspected. That is an integration hypothesis, not proof of the best operation coverage, startup, quality, VRAM use or Windows containment. ComfyUI may support a needed conditioning workflow sooner; native model pipelines may expose features absent from either abstraction. Conversely, ComfyUI custom-node/ecosystem closure can be much harder to freeze and review. The winner must be an exact operation on exact software/model/hardware, not a framework chosen for its README.

Before evaluation, replace the public assumption that `EngineGraph.nodes[class_type]` plus whole in-memory file bytes is a provider-neutral contract. Current `core/engines/contract.ts` explicitly uses that representation and has engines disabled; preserve its tests while versioning the seam. Proposed **OperationRequest v2** carries operation/schema version, expected canonical revision, granted asset IDs and source-time references, bounded controls, desired duration/resolution/rate/audio mode, local/catalog model revision, seed policy, attempt/idempotency identity and explicit consent/resource envelope. Worker-private compilation produces Diffusers parameters, ComfyUI workflow or native argv. Artifacts return via staged file handles/streamed CAS with hashes/probe receipts, not unbounded byte arrays or direct canonical writes.

Operation capability records must distinguish supported/experimental/unavailable and give exact reasons: required runtime/driver, installed model hash, entitlement/region, privacy/egress policy, maximum dimensions/frames/steps, model audio behavior, available controls and known losses. Camera text in a prompt is a soft instruction; applied camera/pose/depth/identity conditioning needs a separate demonstrated capability. Output audio presence must be measured, never inferred from “video model”.

Suggested bake-off after separate authorization: one short text-to-video and one image-to-video operation for a single allowed checkpoint, then the specific identity/control operation the product requires. Run matched consented inputs, model hash and requested settings through candidate implementations; record unsupported options rather than approximate silently. Compare cold/warm p50/p95 latency, peak CPU RAM/VRAM, disk growth, OOM rate, cancel-to-exit, restart/retry behavior, output frame/audio/timing/probe validation and blinded quality/control ratings. Run negative/hostile-worker tests separately from quality experiments. A small dummy-tensor unit test is not a model-quality pass.

No pipeline wins by returning a file after cancellation. A cancellation/revision fence prevents publication even if an underlying library completes; a local cancel fallback must not trigger a paid provider request. Ambiguous remote submit outcomes remain reconciliation-required. Logs exclude tokens, unredacted user paths and private prompts unless expressly consented for diagnostics.

## Maintenance and evidence policy

Assign a media owner to FFmpeg/libass/build provenance; editing owner to pure OpenCut modules; interchange owner to OTIO; generation owner to runtime/model catalogs and adapter schemas; audio owner to transcription timing/quality. One owner is accountable for each operation contract and its qualification fixtures. Prefer incremental upstream security updates behind pinned recipes and regression receipts. Monthly drift reports discover updates; they do not auto-upgrade donor code or weights.

When a donor changes, inspect the actual selected file/dependency delta and known advisories, then repeat affected tests. When models/drivers/backends change, produce a new operation capability/qualification record. Preserve older model receipts so projects explain why a result cannot be reproduced. Keep third-party notices and model attribution out of product names while making required attribution accessible.
